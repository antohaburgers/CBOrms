# СВО’rms — Alpha 0.2

**Тактическая пошаговая артиллерия для двух игроков на одном устройстве.** Солдаты вместо червяков; в центре игры — баллистика, перемещение по большой карте, четыре вида оружия и полностью разрушаемая земля.

Игра работает в браузере без сборки и внешних зависимостей. Telegram Mini App и онлайн-мультиплеер пока **не реализованы**.

**Играть через GitHub Pages:** https://antohaburgers.github.io/CBOrms/

Если Pages ещё не включён: **Settings → Pages → Deploy from a branch → main / (root) → Save**.

## Что появилось в Alpha 0.2

- Мир **3840 × 960** (в три раза длиннее карты Alpha 0.1); камера отображает область 1280 × 720 и автоматически следует за бойцом/снарядом.
- Смешанный рельеф: холмы, склоны, ущелья, разрушаемые мосты, надземные платформы и подземные проходы.
- По **пять бойцов** в каждой команде: случайный разброс вокруг пяти позиций в каждой половине поля. Стороны разделены.
- Ходы идут без таймера, бойцы команды чередуются; нельзя вручную выбрать любого.
- На ход **180 условных единиц** перемещения и **один выстрел**.
- Прыжки доступны при наличии земли под ногами, каждый прыжок расходует **25 единиц** перемещения. Прыгать можно неоднократно при достаточном запасе.
- Урон при падении с большой высоты. Взрывы отбрасывают персонажей.
- **Дружественный огонь включён:** взрывы и пули повреждают и своих бойцов.
- Воронки имеют неровные края без прежнего искусственного кругового контура.
- Оружейный селектор и счётчик командных убийств.

## Четыре вида оружия

| Оружие | Лимит | Эффект |
|---|---|---|
| **Гранатомёт** | ∞ | Снаряд летит по баллистической траектории, при ударе взрывается и вырезает воронку |
| **Автомат** | ∞ | Очередь из 10 пуль с отдачей и небольшим разбросом; удобен для ближней дистанции |
| **Кластерная граната** | **2 на команду за матч** | Граната отскакивает от грунта и детонирует по таймеру, выпуская пять мини-гранат со своими взрывами |
| **Артиллерия** | **1 заряд за каждые 3 убийства врагов командой** | Выбор точки на карте; прилёт тяжёлой ракеты с главным взрывом и четырьмя дополнительными. Суммарно около пяти обычных гранатомётных ударов |

Командные убийства учитываются только при гибели противников от урона команды, а не при гибели своих. Артиллерийский заряд расходуется при выстреле, накопление продолжается. При отсутствии боеприпасов соответствующая кнопка недоступна.

## Управление

| Действие | Телефон | Компьютер |
|---|---|---|
| Шаг влево/вправо | Удерживать ◀ / ▶ | A / D либо ← / → |
| Прыжок | Кнопка «ПРЫЖОК» | J |
| Прицел | Перетащить по полю, либо ± | Мышь по полю, W/S или ↑/↓ |
| Мощность | Ползунок | Ползунок |
| Выбрать оружие | Кнопки арсенала | 1, 2, 3, 4 |
| Выстрел | «ОГОНЬ!» | Пробел / Enter |
| Обзор карты | «ОБЗОР», затем перетаскивать поле | C, затем перетаскивать |
| Вернуться к бойцу | «К БОЙЦУ» | F |
| Прицел артиллерии | Выбрать артиллерию, коснуться точки | Выбрать артиллерию, щёлкнуть по точке |
| Новый матч | «НОВЫЙ МАТЧ» | R |

**Выбор далёкой цели для артиллерии:** нажмите «ОБЗОР», прокрутите карту до цели, коснитесь цели без перетаскивания — появится прицельная метка. Затем нажмите «ОГОНЬ!». Сразу после выстрела камера возвращается к автоматическому слежению.

Верхняя мини-карта показывает расположение живых солдат и прямоугольник текущей камеры.

## Техническая реализация

- `index.html` — интерфейс и доступные действия.
- `styles.css` — адаптивная компоновка телефона и ПК.
- `game.js` — состояние матча, проверка столкновений, камера, физика и отрисовка Canvas 2D.
- Мир с маской грунта `Uint8Array` и отдельным буфером текстуры; деформация синхронизирует оба представления.
- Локальная физика попаданий/падений и визуальные эффекты без сервера.

## Что ещё предстоит

Alpha 0.2 — прототип баланса. Реальные матчи понадобятся, чтобы настроить дальность автомата, прыжки, взрывной урон, размер воронок и положение мостов. После отладки — анимации, звуки, новые карты и интеграция с Telegram.

### Принятые решения для будущих версий

Пользователь утвердил: карта втрое длиннее; смешанный многоуровневый рельеф; автокамера с ручным обзором; команды 5×5 со случайными разделёнными позициями; ходы солдат по очереди; фиксированное перемещение; неограниченное число прыжков в пределах запаса движения; урон от высоты; автомат очередью 10 пуль; кластер с отскоком и 5 мини-гранатами; 2 кластера на матч для каждой стороны; ульта каждые 3 командных убийства; артиллерия с тяжёлой ракетой и вторичными взрывами; дружественный огонь; отсутствие таймера.

# СВО’rms — Alpha 0.1

Пошаговая 2D-артиллерия с солдатами вместо червяков. Главные механики: **физика, баллистика и разрушаемая земля**.

Сейчас доступна **браузерная дуэль для двух игроков на одном устройстве**. Мультиплеер через Telegram-чаты пока в планах.

## Запуск

Для локальной игры откройте `index.html` в браузере. Сборка и сервер не нужны.

Для публичной ссылки откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите **main / (root)** и нажмите **Save**. После успешной публикации адрес будет: https://antohaburgers.github.io/CBOrms/

## Управление

| Действие | Телефон | Компьютер |
|---|---|---|
| Прицел | Провести пальцем по полю или ± | Мышь по полю, W/S или ↑/↓ |
| Мощность | Ползунок | Ползунок |
| Движение | Удерживать ◀ / ▶ | A/D или ←/→ |
| Выстрел | «ОГОНЬ!» | Пробел / Enter |
| Новый матч | Кнопка сверху | R |

У каждого отряда три солдата. На ход доступно 90 единиц перемещения и один выстрел. Сила выстрела и направление ветра влияют на полёт снаряда. Взрыв вырезает воронку, повреждает и отбрасывает солдат. После выстрела ходит другая команда. Побеждает последний оставшийся отряд.

## Сделано в Alpha 0.1

- Поле с процедурным пейзажем и пиксельной маской разрушаемого грунта.
- Гравитация, ветер, прицел с прогнозом траектории, регулируемая мощность.
- Взрывы, воронки, частицы земли и дыма.
- Урон по радиусу, отбрасывание, падение, HP, смена ходов и финал матча.
- Сенсорное и клавиатурное управление.

## Дорожная карта

1. **Alpha 0.2:** улучшить физику падения и перемещения, новые типы оружия.
2. **Alpha 0.3:** анимации, реалистичнее выглядящие бойцы, звуки, дополнительные карты.
3. **Telegram Mini App:** авторизация, приглашения из чатов, комнаты и серверное состояние игры.
4. **Асинхронный мультиплеер:** сохранение ходов, восстановление матча и уведомления сопернику.

Для честной сетевой игры сервер должен подтверждать расчёт выстрела, попадания и изменение рельефа.

## Структура

- `index.html` — интерфейс игры.
- `styles.css` — адаптивный дизайн.
- `game.js` — физика, управление, игровое состояние и Canvas 2D.

> Ранний прототип для проверки игрового процесса, не финальный баланс или графика.
